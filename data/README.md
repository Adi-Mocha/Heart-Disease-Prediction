# Data

**Source:** UCI Machine Learning Repository, Heart Disease dataset (Cleveland subset)
https://archive.ics.uci.edu/dataset/45/heart+disease

303 patients, 13 clinical features. The original target `num` (0-4) is converted to
binary (0 = no disease, 1 = disease).

Running the notebook downloads the data with `ucimlrepo` and saves `heart_disease.csv` here.
